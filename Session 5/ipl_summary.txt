TASK 4: Spotify Playlist Filter

Prompt used:
"Write a simple Python function that takes a list of song names and returns only the songs that start with the letter S. Make it case-insensitive and include a short example."

Code generated:
def filter_songs_starting_with_s(song_names):
    return [song for song in song_names if song.lower().startswith("s")]

songs = [
    "Shape of You",
    "Blinding Lights",
    "Senorita",
    "Perfect",
    "Someone Like You",
    "Levitating"
]

filtered_songs = filter_songs_starting_with_s(songs)
print(filtered_songs)

Expected output:
['Shape of You', 'Senorita', 'Someone Like You']

Explanation:
The function checks each song name and keeps only names that begin with the letter S, regardless of whether the first letter is uppercase or lowercase.

TASK 5: Production Challenges for Generative AI Chatbots

1. Challenge: Incorrect or fabricated answers
Generative AI chatbots may provide inaccurate information about movie schedules, ticket availability, product details, prices, or return policies.
Solution: Connect the chatbot to trusted, up-to-date company databases and APIs, and use validation and fallback responses when information is unavailable.

2. Challenge: Privacy, security, and high operating costs
Chatbots may process sensitive customer information, face prompt-injection attempts, or become expensive to operate at high traffic volumes.
Solution: Minimize and protect personal data, apply access controls and input/output safeguards, and use caching, monitoring, and efficient models to control costs.

CONCLUSION
Generative AI can summarize news, answer customer questions, create images, and help write useful code. In production, companies must also ensure accuracy, privacy, security, and cost efficiency.
